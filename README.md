# Build_your_own_pc# PcBuilds

PcBuilds är en responsiv webbplats skapad som slutprojekt i kursen Webbutveckling 1.

På webbplatsen kan användaren:

- Utforska färdigbyggda datorer (PreBuilds)
- Söka efter datorer
- Bygga en egen dator genom att välja komponenter
- Spara sin build och gå till checkout
- Läsa vanliga frågor
- Kontakta support via formulär

# Tekniker

Projektet är byggt med:

- HTML5
- CSS3
- JavaScript

# Funktioner

- Responsiv design för mobil och dator
- Hamburgermeny
- Modal-fönster
- FAQ-system
- Sökfunktion
- LocalStorage för att spara builds
- Dynamisk DOM-manipulation

# Starta projektet

1. Ladda ner eller klona projektet.
2. Öppna `index.html` i en webbläsare.
